# Trade finance documentary credit examination (PRIVATE)

Private design record. The construction is generated by `solution/generate.py`; the six desk methods live in `solution/estimators.py`. Neither file enters the agent work image. The judge image carries only `tests/`, including frozen truth and the frozen scorer manifest. It has no estimator, generator, floor-setting portfolio or author measurements.

## What is graded

Six independently fitted lanes, equal weight, purely additive. Every target is a deterministic fitted functional of public observations. Randomness creates public completed-case observations only; no future outcome draw is graded. The oracle recomputes outputs from those observations and does not copy hidden truth. Its score is the attainability endpoint, not the best independently fitted approximation reported below.

| lane | quantity | own input view | private fitted method | metric |
|---|---|---|---|---|
| discrepancy_count | expected number of discrepancies | presentation_documents | document-route-specific local regression of log-one-plus completed counts | relative agreement penalising both mean and RMS error |
| discrepancy_class_profile | eight class shares with pending-code residual | discrepancy_logs | local nine-category Dirichlet shrinkage toward corridor-specific weighted priors | overlap including the residual |
| refusal_flag | refusal-notice decision | refusal_notices | interaction logistic regression, recency weights and recent-prevalence threshold | positive-class F1 |
| tenor_tier | increasing settlement tenor band | amendment_histories | tenor-basis-specific kernel smoothing of completed settlement days | unweighted macro F1 |
| examiner_priority_rank | dense descending handling-urgency rank in period cohort | correspondent_banks | group-specific periodic ridge basis plus clipped local residual correction | within-ten share, averaged across cohorts |
| charge_reserve | expected USD fees and handling charges | settlement_payments | group-specific local hurdle incidence and empirical-Bayes log severity | relative agreement on currency magnitude |

The estimators share only transport and stateless numerical helpers. They have independent observations, responses, parameters, weighting and fitted state. The register supplies categorical attributes that are intentionally absent from snapshots, requiring joins. No target is a disguised copy of another lane. Priority is not a sort of the count, refusal or reserve outputs. Pending class coding is distinct from the classified “other” category and from compliance probability.

## Ledger discipline and regime change

A record at review period q fits closed cases with `booked_period < q`. If a row was restated at or after q, its original `as_booked` outcome enters the fit; otherwise its corrected top-level outcome enters. The manual defines those fields without prescribing the fitting policy. A historical record is not retroactively restated. Source files contain both historical and later observations, so reading the whole corrected ledger without point-in-time filtering is a tempting but wrong shortcut.

The generator changes completed-case processes at period 14. History periods are 8, 10 and 12; queries are 16 and 20. Recency weighting matters differently in different lanes, and blind recency weighting can be worse. Categorical grouping, response transforms, pending-code shrinkage, prevalence calibration and operational periodicity do not reduce to a single universal modelling choice.

It measures both through the same lane functions used by the verifier, along with historical constants, all flags, every constant tier, uniform profiles and every point mass. `floors.json` stores every floor-setting method's raw metrics and complete reports, the exact source hashes, the truth and manifest hashes, and hashes for the entire public workspace. ## Failure modes and authoring observations

- The host's default Python was incompatible with the pinned numerical wheels. This refresh used an isolated CPython environment with the pinned dependencies; the certification records its versions in `measurements/verification.json`. No system packages were changed.
- The first floor portfolio omitted the default history forest. The final portfolio measures both natural one-shot approaches, with the explicit lane-specific exclusions described above. The regenerated hybrid score is **0.4839** (`measurements/ladder.json`); historical results remain in `measurements/initial_experiment.json`, not misrepresented as final results. Neither generator nor oracle was changed for this refresh.
- Closed-case outcomes are noisy observations; predicting them is not the same as reproducing a desk's fitted functional. Boosted and randomized trees did not dominate. The initial distribution constant even beat the closed-case forest, while the history forest beat both.
- Recency was not a universal improvement: `kernel_plain` earned **0.0441**, while `kernel_recent` earned **0.0433** after final flooring (`measurements/ladder.json`). A solver must identify lane-specific estimation rather than apply one weighting rule blindly.
- Grouped kernels alone left the local log-count structure unmodelled. Local log fitting raised the aggregate from **0.0886** to **0.2258** (`measurements/ladder.json`), but did not fix refusal calibration or periodic priority. The hybrid did.
- The smallest tenor class has only **13** graded cases. Support-weighted F1 would hide poor performance there. The scorer uses unweighted F1 across all occurring classes. Independent review found that the reference-style valid-only F1 times coverage rule could reward selectively withholding a rare-class error. It was replaced with adverse binary decisions for invalid flags and all adverse one-vs-rest errors for invalid tiers. A regression test compares selective invalidity against every admissible class choice. Valid complete predictions, floor-setting outputs and measured ladder values are unaffected.
- The reference scorer accepted non-integral and out-of-range ranks through its generic finite-number check. This implementation explicitly requires integer ranks in the period-cohort range. Non-finite tokens are rejected lane-locally rather than erasing valid unrelated fields. Both differences are documented in the public rules.
- The editor language server was rooted in the governed parent and could not resolve the bundle-local NumPy installation or use its local Pyright configuration. It also reported nullable import-spec and heterogeneous-row inference issues; explicit loader assertions and appropriate dynamic row/working-value declarations addressed those source issues. Native executable checks use the pinned bundle-local environment. Editor dependency-resolution errors are not represented as a clean LSP result.
- Reference study covered the main instruction, configuration, design record, generator, estimator, portfolio, floor logic, scorer, packaging and check sources, plus representative measurements and data. **It did not exhaustively read every file and every data row in the reference tree before authoring.** That procedural requirement was not met; no exhaustive-read claim is made.

## Reproduction and evidence boundaries

From the bundle root, using Python with `environment/requirements.txt` installed:

```sh
export PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python3 -B solution/measure.py determinism
python3 -B solution/measure_floors.py
python3 -B solution/measure.py ladder
python3 -B solution/checks/verify_bundle.py
```

The determinism command runs the generator twice and diffs every generated byte, not just truth. `nonregression.json` records the compared paths and hashes. The verification command checks source binding, all dataset joins, lane deletion independence, exact oracle regeneration, mechanical alternate layouts, hostile submissions and the actual shell verifier's numeric reward carriers. Its result is stored in `verification.json` only if all assertions pass. Alternate layouts are mechanical invariance checks, not independent reimplementations of the mathematics.

The supplied LICENSE attributes this task; certification checks its terms against the reference when available. The task identity is in `task.toml`. Docker contexts isolate public workspace data from private judge and oracle files. Docker image builds and Linux cross-platform numerical reproduction have not been established by the native Python measurements.

These are author-side deterministic probes, not agent pilot or difficulty evidence. No full-budget agent trajectory was run for this new task. Its timeout allows the requested long run, but the reference's rounds, elapsed hours, pass rate and asymptotic behaviour cannot honestly be attributed to this bundle.
